# SJSU Majors Scraper

The membership form imports SJSU major options from:

```txt
src/app/(public)/membership/data/sjsuMajors.ts
```

That file is generated by:

```txt
scripts/scrape-sjsu-majors.mjs
```

The scraper is intentionally outside `src` and `public`, so it is not served as part of the website.

## Regenerate From The Live Catalog

```sh
npm run scrape:sjsu-majors
```

By default, this reads:

```txt
https://catalog.sjsu.edu/content.php?catoid=17&navoid=7689
```

and writes:

```txt
src/app/(public)/membership/data/sjsuMajors.ts
```

## Regenerate From Saved HTML

SJSU sometimes returns an AWS WAF browser challenge to automated requests. If the live command fails:

1. Open `https://catalog.sjsu.edu/content.php?catoid=17&navoid=7689` in a browser.
2. Save the rendered page HTML locally.
3. Run:

```sh
npm run scrape:sjsu-majors -- --input path/to/saved-catalog.html
```

## Filtering Rules

The scraper keeps only undergraduate and master's-level degree-seeking majors.

It includes degree suffixes such as `BA`, `BS`, `BFA`, `BM`, `MA`, `MS`, `MFA`, `MBA`, `MPA`, `MPH`, `MSW`, `MLIS`, and `MUP`.

It excludes minors, certificates, credentials, concentrations, professional certificates, and doctoral programs.
